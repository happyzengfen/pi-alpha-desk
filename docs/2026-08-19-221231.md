## 主要更新内容

### 文件预览

- 新增通用 `PreviewToolbar`，为表格、文本、Markdown 和图片预览提供刷新、适应宽度与缩放控制。
- DOC/DOCX 在 Windows 上可通过 Microsoft Word 或 WPS COM 转换为 PDF，接入现有连续分页预览。
- Word/WPS COM 不可用时回退到原有 DOC/DOCX HTML/文本预览，避免 macOS、Linux 或未安装 Office 的 Windows 环境发生功能回退。
- 图片手动缩放不再被 `max-width: 100%` 限制；图片模式不启动无意义的文件变更轮询。
- 新工具栏文案接入现有英文/简体中文 i18n 目录。

### Office 与桌面运行时修复

- CSV/TSV 读取前剥离 UTF-8 BOM，同时继续按 UTF-8 解析无 BOM 文件。
- PowerPoint 转换脚本使用 `[string][char]92` 生成 Windows 反斜杠，避免构建链转义丢失。
- Electron Node runtime 以大小写不敏感方式查找 `PATH`/`Path` 环境变量，修复 Windows 启动 PowerShell 时的 `ENOENT`。
- 对用户已打开的 Word 文档使用 `ExportAsFixedFormat` 导出 PDF；仅允许一次性磁盘副本回退到 `SaveAs`，避免改变用户文档的名称或关联状态。

### 版本一致性

- PR 原始提交只更新了 `package.json`，导致三平台 Quality 均出现 `0.8.7 !== 1.0.0` 断言失败。
- 合并前同步更新 `package-lock.json`、`bundled-skills/manifest.json` 与 `bundled-plugins/manifest.json` 的应用版本为 `1.0.0`。
- 新增预览工具栏、图片缩放、Word 回退与非破坏性 COM 导出的回归测试。

1. 用 `gh pr list/view` 确认唯一目标、base/head SHA、来源仓库、可合并状态和改动范围。
2. 在隔离 worktree 中检出 PR head，保留当前工作分支及其未推送提交不变。
