## 主要新增与修复

### 会话与 Agent 运行

- 修复首条消息 Fork 只返回新 session id、但没有真实 JSONL 文件的问题；新会话会先写入合法的 v3 session header，再返回给 UI。
- 补充 Fork 创建、父会话关系、删除闭环和 cwd 校验测试。
- 保留 run id、SSE reconciliation、最终 flush 和旧 run 事件隔离，避免旧事件复活已结束的 streaming 状态。
- 将新会话 cwd 校验提取到 `lib/new-session-cwd.ts`，满足 Next.js 16.3 Route Handler 的导出约束。

### 文件、主题与数据完整性

- 文件 allow-list 改为比较最近现存祖先的真实路径，阻止根目录内符号链接跳转到授权根外；同时覆盖尚未创建的后代路径。
- 文件 watch 使用 `{mtimeMs, size}` 快照去重，避免单次文件变化触发成千上万次重复 UI 更新。
- 上传覆盖改为同目录临时文件加原子 `rename`，不再先删除旧文件。
- 凭据写入改为锁内私有原子替换，并保持 `0600` 权限；首次创建使用排他写入。
- 主题 HTTP 接口拒绝路径型主题名和未授权 `cwd`，但保留 Pi SDK 内部直接主题路径能力。
- OAuth 手工回调 token 改用 `randomUUID()`。

### Electron 与 macOS

- BrowserWindow 启用 sandbox，并增加 exact-origin 导航、外部协议、新窗口和 webview 限制。
- 所有 preload/IPC 入口增加主 frame 与 Renderer origin 校验。
- `showItemInFolder` 在调用系统 shell 前先通过服务端文件 allow-list 授权。
- 服务进程异常退出时显示日志路径、末尾输出、code/signal，并完整退出，不再被托盘 close handler 隐藏。
- 保留并验证 macOS `Cmd+C`、`Cmd+V`、`Cmd+X`、`Cmd+A`、撤销/重做等编辑快捷键，以及原生编辑菜单 fallback。
- bundled skills 尊重 `PI_CODING_AGENT_DIR`，测试 profile 不再污染真实用户 Skill 目录。
- 增加仅在 `PI_WEB_BENCHMARK=1` 时启用的本地启动/Chromium 指标；默认不采集、不上传遥测。

### 安全响应与依赖

- 增加 `frame-ancestors 'none'`、`X-Frame-Options: DENY`、`nosniff`、`no-referrer` 和受限 Permissions Policy。
- Next.js 升级到 `16.3.0`，Mermaid 升级到 `11.16.1`，Undici 升级到 `8.10.0`，`eslint-config-next` 与 Next 对齐。
- 删除未使用的 `to-ico` 依赖及其旧传递依赖。
- Webpack server build 将 Undici 保持为 Node runtime dependency，修复 instrumentation 导致的开发 API 500。
- 生产构建显式使用 `next build --webpack`，避免本地 Electron 服务端打包路径漂移。
- 完整生产与开发依赖审计结果为 `0 vulnerabilities`。
